My first HTML document

The browser tab shows the title. The page shows the body.

Quick discussion

HTML means HyperText Markup Language. It describes a webpage's structure using elements. In <p>Hello</p>, the opening tag, text, and closing tag together form a paragraph element.

  • <!DOCTYPE html> declares an HTML document and selects standards mode.
  • <html lang="en"> is the root element and identifies the page language.
  • <head> holds metadata; <title> names the browser tab.
  • <body> contains the page content the browser displays.

The browser reads the markup and displays the content; it does not show the tags as ordinary page text.

Try it: Change the title and the main heading, save, and refresh. Which change appears in the tab, and which appears on the page?
