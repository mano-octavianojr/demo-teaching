Quick discussion

<a> creates a link. Its href attribute supplies the destination; the text between its tags is the link label. Here, href="#projects" targets the element with id="projects" on this page. Each ID must be unique.

A destination can also be another local file or a full website URL. These examples use same-page links so they work offline.

Try it: Activate Explore my projects with a mouse, then use Tab and Enter to follow Return to About. Check the matching IDs in the source even if the page is too short to scroll.
