Quick discussion

<img> embeds an image. Its src attribute points to the file, and alt provides a text alternative for people who cannot see it. Here the path starts from this HTML file's folder and enters assets.

The width and height attributes give dimensions in pixels. <img> is a void element: it has no content or closing tag.

Try it: Locate the image in the assets folder and explain how its path matches src. Read the alternative text: does it identify the meaningful image?
