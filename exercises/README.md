# Assignment: add Interests to the portfolio

Complete this **after class**. The final teaching segment only introduces the task.

1. Copy the entire `portfolio-starter` folder to your own working folder. Keep its `assets` directory.
2. Open `index.html` in a text editor and in a browser.
3. Inside `main`, add a `section` after Projects with the unique ID `interests`.
4. Give it an `h2` heading, `Interests`, and an unordered list of at least two interests.
5. Inside the navigation list, add a descriptive `Interests` link with `href="#interests"`.
6. Save, refresh, and activate the link using both a mouse and the keyboard.

## Expected result

The original About, Skills, and Projects sections remain. A new **Interests** heading and two bullet points appear before the footer. The navigation has an **Interests** link that targets that section. The result uses the browser's default appearance; CSS is next week's topic.

## Submission

Submit the complete folder, including `index.html` and `assets`, plus a screenshot of the updated page using your instructor's chosen channel. Be ready to explain the new `section`, `id`, `h2`, `ul`, `li`, and `a` elements. No submission service or deadline is assumed here.

## Self-check

- One main `h1`, an `h2` for Interests, and one unique `id="interests"`.
- At least two `li` items inside `ul`.
- An `href="#interests"` link inside `nav`.
- Original content, image, and working links preserved.
- No CSS or JavaScript needed.

GenAI may help, but verify its output and explain and modify every line you use.
